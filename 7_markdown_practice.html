AI(Codex, ChatGPT)는 줄글보다 # 제목, - 목록, **강조**, `코드`, |표|로 구조화된 지시를 훨씬 정확하게 이해합니다. 우리가 작성하는 prompts.md, 나만의 자동화 지침서 SKILL.md, 그리고 일일 운영 브리핑 결과물(daily_brief.md) 모두 마크다운으로 작성됩니다.

# 자재 납기 지연 분석 프롬프트

## 역할
너는 케이조선 자재·조달 데이터 분석 도우미야.

## 맥락
`data/material_orders.csv` 파일의 기준일은 `2026-11-13`이야.

## 명령
1. 납기일이 기준일보다 이전이고 `remaining_qty > 0`인 지연 행을 추출해.
2. **중요 자재(`critical == "Y"`)** 건수와 지연 금액 합계를 계산해.

## 출력 형식
| 구분 | 건수 | 비고 |
| --- | --- | --- |
| 전체 지연 | 94건 | 당일 납기 제외 |
| 중요 지연 | 47건 | 우선 조치 대상 |

> 주의: 원본 CSV 파일은 절대 수정하지 마.

# 일일 운영 브리핑 생성과 검증

1. `daily_brief.py`와 입력 CSV 2종을 확인한다.
2. 실행 전 `SHA256` 해시를 기록한다.
3. `.venv` 파이썬으로 `--as-of 2026-11-13` 옵션을 실행한다.
4. `generated/` 폴더의 결과 5종과 **원본 보존 여부**를 검증한다.
