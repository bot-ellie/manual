PowerShell 실행 권한 모드 설정

Windows 기본 정책으로 인한 .ps1 차단 에러를 예방하는 방식을 선택하세요.

사전 1회 필수 PowerShell에서 권한 해제 명령어 실행

아래 명령어를 PowerShell에 입력하면 .cmd 없이 일반 npm, codex 명령을 쓸 수 있습니다.

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

Step 1. 터미널 열고 winget 정상 작동 점검

Windows 검색창에서 PowerShell을 실행한 뒤, 아래 명령어를 입력하여 winget이 설치되어 있는지 확인합니다.

PowerShell
winget --version
버전 번호가 정상 출력된 경우

예: v1.8.x...

빨간색 에러 / 인식 불가 메시지인 경우

'winget' 용어가 cmdlet, 함수... 이름으로 인식되지 않습니다.

Step 2. 필수 개발 도구 4종 일괄 설치

아래 일괄 명령어를 복사해 터미널에 붙여넣으면 4개 프로그램이 차례대로 자동 설치됩니다.

# Git 설치
winget install --id Git.Git -e
# VS Code 설치
winget install --id Microsoft.VisualStudioCode -e
# Node.js LTS (npm 포함)
winget install --id OpenJS.NodeJS.LTS -e
# Python 3.15
winget install --id Python.Python.3.15 -e

개별 설치가 필요할 경우

Git (버전 관리) Git.Git

로컬 코드의 변경 내역을 저장하고 GitHub와 연결하는 도구

winget install --id Git.Git -e
VS Code (편집기) Microsoft.VisualStudioCode

코드 작성 및 터미널, Git 연동을 지원하는 통합 에디터

winget install --id Microsoft.VisualStudioCode -e
Node.js LTS (npm 포함) OpenJS.NodeJS.LTS

JavaScript 실행 환경 및 npm 패키지 매니저 동시 탑재

winget install --id OpenJS.NodeJS.LTS -e
Python 3.15 Python.Python.3.15

데이터 분석 및 웹 앱 개발을 위한 최신 파이썬 런타임

winget install --id Python.Python.3.15 -e

Step 3-1. 설치된 5종 도구 버전 확인

설치 후 PowerShell 창을 닫고 새로 연 다음 실행해야 환경변수(PATH)가 정상 적용됩니다.

Git 버전 git --version
VS Code 버전 code --version
Node.js 버전 node --version
npm 패키지 매니저 npm --version
Python 3.15 버전 py -3.15 --version

Step 3-2. OpenAI Codex CLI 전역 설치 및 버전 확인

npm을 활용하여 AI 코딩 보조 도구인 Codex CLI 패키지를 컴퓨터 전역(Global)에 설치합니다.

- winget은 Windows 프로그램을 설치하는 도구입니다.
- npm은 Node.js 패키지와 CLI 도구를 설치하는 도구이며 일반적인 Node.js 설치에 포함됩니다.
- -g는 Codex CLI를 여러 폴더에서 실행할 수 있도록 설치하는 옵션입니다.
1. Codex 전역 설치 실행
npm install -g @openai/codex
2. Codex 설치 확인
codex --version

Step 4. 실습 프로젝트별 독립 가상환경(.venv) 구축

02_material, 04_quality, 05_automation 3개 폴더는 서로 다른 프로젝트입니다. 각 폴더마다 가상환경을 각각 구축하고 패키지(pandas, streamlit)를 설치해야 사전 준비가 완전히 종료됩니다.

왜 activate(가상환경 활성화) 대신 직접 경로를 써서 실행할까요?

PowerShell의 보안 차단 오류를 원천 차단하고, 여러 터미널을 열었을 때 어떤 파이썬인지 헷갈리지 않도록 가상환경 내부의 .\.venv\Scripts\python.exe를 직접 지정하여 안전하게 실행합니다.

명령어 의미: pwd & Get-ChildItem

• pwd: 내가 지금 올바른 실습 폴더 위치에 들어와 있는지 확인

• Get-ChildItem: 폴더 내 파일 목록을 확인 (Windows의 dir, Mac의 ls와 동일)

starter/02_material

02_material 폴더 가상환경 및 라이브러리 세팅

1. 가상환경을 설정할 폴더로 이동(폴더 위치가 각자 다르므로 이 명령은 복사되지 않습니다.) - 또는 VS Code를 실행하고, VS Code에서 해당 폴더를 연 후(File - Open Folder), 터미널(Terminal - New Terminal)을 열어서 2~5번 명령을 실행해도 됩니다. cd "폴더 경로"
2. 경로 확인 및 파일 목록 점검 pwd ; Get-ChildItem
3. 파이썬 3.15 가상환경(.venv) 생성 py -3.15 -m venv .venv
4. 가상환경 내부로 requirements.txt 설치 (직접 경로) .\.venv\Scripts\python.exe -m pip install -r requirements.txt
5. pandas 및 streamlit 설치 검증 .\.venv\Scripts\python.exe -c "import pandas, streamlit; print(pandas.__version__, streamlit.__version__)"

Step 5. winget 복구 및 공식 사이트 직접 설치

winget이 실행되지 않거나 사내 보안 정책상 터미널 설치가 차단된 경우 아래 방법을 통해 설치를 완료하세요.

A Microsoft Store에서 winget(앱 설치 관리자) 복구하기

  1. Windows 시작 메뉴에서 Microsoft Store를 실행합니다.
  2. 상단 검색창에 '앱 설치 관리자' (영문: App Installer)를 검색합니다.
  3. [업데이트] 또는 [설치] 버튼을 누른 뒤 완료되면 터미널을 다시 엽니다.
  4. 스토어 접속이 불가한 경우, 공식 winget GitHub Releases에서 최신 .msixbundle 파일을 직접 내려받아 실행합니다.
