프롬프트 입력창 슬래시(/) 명령어 5종 완벽 해설

Codex 세션 실행 중 /를 입력하면 프로젝트 설정, 권한 제어, 코드 리뷰를 즉시 제어할 수 있습니다.

/init

프로젝트 지침 파일 생성 (AGENTS.md)

현재 폴더의 특성, 코딩 컨벤션, 규칙을 담은 AGENTS.md를 생성합니다.

💡 활용 팁: "이 프로젝트는 Streamlit을 사용하며 한국어 주석을 달아야 함" 같은 기본 규칙을 명시해두면 매 대화마다 반복 설명할 필요가 없습니다.
/status

현재 세션 상태 및 설정 확인

현재 선택된 AI 모델, 토큰 소비량, 작업 폴더 경로, 보안 승인 모드 등의 세션 설정을 일목요연하게 표시합니다.

💡 활용 팁: 대화가 길어져 컨텍스트가 얼마나 찼는지, 올바른 모델이 선택되었는지 점검할 때 유용합니다.
/permissions

도구 실행 권한 정책 설정

Codex가 파일을 읽고 쓰거나, 터미널 명령을 실행할 때 매번 사용자 확인을 받을지(Ask), 전자동으로 실행할지(Auto)를 선택합니다.

💡 권장 설정: 초보자 수업 때는 실수 방지를 위해 Read: Auto, Write: Ask, Exec: Ask 구성을 권장합니다.
/model

추론 모델 및 추론 강도(Reasoning Effort) 변경

상황에 맞춰 더 똑똑한 고성능 모델이나 가벼운 실시간 응답 모델로 전환하고, 생각하는 깊이(low/medium/high)를 조정합니다.

💡 설정 기준: 복잡한 조선 데이터 정제·통계 분석은 high, 단순 UI 문구 수정은 low가 효율적입니다.
/review

작업 변경점 종합 리뷰 및 버그 진단

현재 세션에서 수정된 모든 파일의 코드 변경(Diff)을 AI가 자동으로 검토하여 미처 발견하지 못한 잠재적 버그, 보안 취약점, 예외 처리 누락을 찾아냅니다.

💡 필수 절차: 코드를 실행하거나 Git에 커밋하기 직전 /review를 한 번 돌려 검증받는 습관을 들이면 오류를 90% 이상 예방할 수 있습니다.

프롬프트 하단 핵심 내비게이션 단축키

터미널 인터페이스 하단에 안내되는 직관적인 키보드 컨트롤 방법입니다.

← (왼쪽 화살표)

에이전트 모드 전환 (for agents)

단순 챗봇 모드에서 파일 작성, 명령 실행, 디버깅을 주도적으로 수행하는 특화 서브 에이전트 목록을 열고 선택합니다.

? (물음표 키)

단축키 도움말 (for shortcuts)

대화 취소(Ctrl+C), 멀티라인 입력, 세션 종료 등 지원되는 모든 핫키 목록을 화면에 즉시 띄웁니다.

Ctrl + C

현재 실행 중단 / 답변 취소

AI가 답변을 생성 중이거나 긴 명령어를 실행하고 있을 때 안전하게 즉시 중단합니다. (두 번 누르면 Codex 종료)

Shift + Enter

줄바꿈 (Multi-line 입력)

단순 엔터는 명령어 전송이며, 여러 줄의 요구사항이나 코드 스니펫을 함께 붙여넣을 때 줄바꿈으로 활용합니다.

조선/제조 실무 실습을 위한 실전 프롬프트 예시

복잡한 문법 대신 자연어로 명확하게 요구사항을 전달하는 표준 패턴입니다.

데이터 분석 & Streamlit 시각화

"선박 자재 데이터인 material_spec.csv 파일을 분석해서, 규격별 단가와 납기일을 인터랙티브하게 필터링할 수 있는 Streamlit 웹 앱 코드를 app.py로 작성해줘."

에러 디버깅 & 자동 수정

"터미널에서 실행했을 때 KeyError: 'plate_thickness' 오류가 발생했어. 데이터 컬럼명을 확인해서 안전하게 예외 처리되도록 코드를 고쳐줘."

품질 검사 자동화 스크립트

"용접 부위 비파괴 검사(NDT) 로그를 읽어서 허용 오차를 초과한 행들만 빨간색으로 하이라이트된 엑셀 보고서로 저장하는 파이썬 함수 만들어줘."

자주 발생하는 오류 해결 (Troubleshooting)

실습 중 마주칠 수 있는 대표적인 터미널 오류와 원클릭 대처 방법입니다.
