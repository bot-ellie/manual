조선 자재·품질·자동화 데이터 분석용 UI 컴포넌트 & 코드 레퍼런스

실습 대시보드 전용

Streamlit(스트림릿)이란?

HTML/CSS/JS 없이 순수 파이썬 코드만으로 인터랙티브한 웹 대시보드를 제작하는 오픈소스 프레임워크입니다. 사용자가 필터를 조작하면 파이썬 스크립트가 위에서부터 아래로 재실행되어 실시간 분석 결과를 반영합니다.

화면 타이틀 및 텍스트 출력 함수

대시보드의 계층 구조를 잡고 설명문을 기재할 때 사용합니다.

st.title()

큰 제목 (H1)

대시보드 페이지의 최상단 메인 타이틀을 출력합니다.

st.title("🚢 케이조선 자재 수급 대시보드")
st.header()

중간 제목 (H2)

대시보드의 주요 섹션 또는 분석 단계를 구분할 때 사용합니다.

st.header("1. 선박 블록별 발주 현황")
st.subheader()

소제목 (H3)

표나 차트 바로 위에 붙는 작은 단위의 주제 설명 제목입니다.

st.subheader("납기 지연 의심 부품 목록")
st.write() & st.markdown()

일반 텍스트 및 서식 본문

만능 출력 함수입니다. 텍스트, 데이터프레임, 숫자 등을 알아서 감지해 출력합니다.

st.write("기준일 기준 **미입고 수량**이 남은 품목만 집계됩니다.")

사용자 필터링 및 입력 위젯

선택된 값이 변수에 즉시 할당되어 아래쪽 데이터와 차트를 필터링합니다.

st.selectbox()

드롭다운 단일 선택 메뉴

목록 중 1개 항목을 선택할 때 사용합니다.

dept = st.selectbox("조회할 선종 선택", ["전체", "석유화학제품운반선", "LNG선"])
st.write(f"선택한 선종: {dept}")
st.radio()

라디오 버튼 (상호 배타적 선택)

모든 옵션을 한눈에 펼쳐놓고 1가지를 고르게 할 때 좋습니다.

status = st.radio("검사 상태 필터", ["전체", "합격", "불합격"])
st.button()

클릭 동작 버튼

클릭한 순간 `True`를 반환하여 특정 동작(계산, 분석)을 실행합니다.

if st.button("분석 실행"):
    st.success("지연율 재계산 완료!")
st.sidebar

사이드바 제어판 배치

화면 좌측 서랍 메뉴에 필터 위젯들을 모아 메인 화면을 깔끔하게 유지합니다.

ship = st.sidebar.selectbox("선종 선택", ["50k 탱커", "115k 탱커"])

표 출력(Excel 스타일) 및 핵심 지표 카드

Pandas DataFrame을 엑셀처럼 인터랙티브하게 조회하고 KPI를 강조합니다.

st.dataframe()

엑셀 형태의 반응형 데이터 표

정렬, 열 크기 조절, 스크롤, 검색이 가능한 인터랙티브 표입니다.

import pandas as pd
df = pd.read_csv("material_orders.csv")
st.dataframe(df, use_container_width=True)
st.table()

정적 고정 표

스크롤 없이 요약된 상위 몇 개 항목을 문서처럼 딱 고정해 보여줄 때 씁니다.

st.table(df.head(5)) # 상위 5건 고정 출력
st.metric()

KPI 핵심 지표 카드 (대시보드 상단 배치용)

현재 수치와 전월/전일 대비 증감(Delta)을 예쁜 카드로 강조합니다.

col1, col2, col3 = st.columns(3)
col1.metric("총 발주 건수", "1,250건", "+12건")
col2.metric("불합격률", "5.0%", "-0.8%", delta_color="inverse")
col3.metric("지연 품목", "8건", "+2건", delta_color="inverse")

그래프 시각화 및 이미지 출력

선박 공정 추이, 불합격 건수 차트 및 도면/현장 사진을 표시합니다.

st.bar_chart() / st.line_chart()

내장 기본 차트 (막대 / 꺾은선)

별도 복잡한 시각화 라이브러리 없이 데이터프레임만 넣으면 즉시 그래프를 그려줍니다.

# 월별 지연 건수 막대 그래프
st.bar_chart(df.set_index("납기월")["지연건수"])
st.image()

이미지 및 사진 출력

로컬 이미지 파일이나 인터넷 URL의 사진을 캡션과 함께 대시보드에 배치합니다.

st.image("ship_photo.jpg", 
         caption="50,000톤급 석유화학제품운반선", 
         use_container_width=True)

파일 다운로드 버튼 & 실전 통합 예제

필터링된 분석 결과를 현업 담당자가 CSV로 내려받을 수 있는 버튼과 완전한 app.py 예제입니다.

st.download_button()

분석 결과 CSV 파일 다운로드 버튼

웹 브라우저를 통해 분석된 데이터를 엑셀 호환 CSV(`utf-8-sig`)로 즉시 내려받게 만듭니다.

csv_data = filtered_df.to_csv(index=False).encode("utf-8-sig")
st.download_button(
    label="📥 필터링 결과 CSV 다운로드",
    data=csv_data,
    file_name="지연품목_분석결과.csv",
    mime="text/csv"
)
app.py 실전 대시보드 올인원 템플릿 
import streamlit as st
import pandas as pd

# 1. 페이지 설정 및 제목
st.set_page_config(page_title="케이조선 자재 분석기", layout="wide")
st.title("🚢 케이조선 자재 납기 모니터링 대시보드")
st.write("기준일 기준 미입고 수량이 남아있는 지연 발주 내역을 실시간 추적합니다.")

# 2. 사이드바 필터 위젯
st.sidebar.header("🔍 조회 필터")
ship_type = st.sidebar.selectbox("선종 선택", ["전체", "석유화학제품운반선", "컨테이너선", "LNG선"])
show_delayed_only = st.sidebar.radio("발주 상태", ["전체 보기", "지연 발주만 보기"])

# 3. 핵심 KPI 메트릭 카드
col1, col2, col3 = st.columns(3)
col1.metric("총 발주 건수", "1,240건", "+15건")
col2.metric("지연 위험 건수", "18건", "+3건", delta_color="inverse")
col3.metric("평균 불합격률", "5.0%", "-0.4%", delta_color="inverse")

# 4. 데이터 표 (엑셀 스타일)
st.subheader("📋 자재 발주 상세 현황")
# 가상 데이터 생성 예시
data = {
    "발주번호": ["PO-101", "PO-102", "PO-103", "PO-104"],
    "선종": ["석유화학제품운반선", "컨테이너선", "LNG선", "석유화학제품운반선"],
    "품목명": ["후판(A급)", "선박용 밸브", "보온 단열재", "고장력 볼트"],
    "미입고수량": [50, 0, 120, 15],
    "상태": ["지연", "입고완료", "지연", "지연"]
}
df = pd.DataFrame(data)

if ship_type != "전체":
    df = df[df["선종"] == ship_type]
if show_delayed_only == "지연 발주만 보기":
    df = df[df["상태"] == "지연"]

st.dataframe(df, use_container_width=True)

# 5. 차트 & CSV 다운로드
col_chart, col_down = st.columns([2, 1])
with col_chart:
    st.subheader("📊 선종별 지연 현황")
    st.bar_chart(df["선종"].value_counts())

with col_down:
    st.subheader("💾 데이터 내보내기")
    csv_bytes = df.to_csv(index=False).encode("utf-8-sig")
    st.download_button(
        label="📥 현재 조회 결과 CSV 다운로드",
        data=csv_bytes,
        file_name="kship_material_filtered.csv",
        mime="text/csv"
    )
