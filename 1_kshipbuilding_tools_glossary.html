1차시 사용 도구

키보드로 AI에게 작업을 지시하고 결과물을 즉시 눈으로 확인하는 기본 도구 3가지입니다.

PowerShell

Windows에 기본 내장된 강력한 명령어 실행 창(쉘)입니다. 폴더 이동, 파일 목록 확인, 프로그램 설치와 실행을 키보드 타이핑으로 수행합니다.

💡 비유: 마우스 대신 글자로 컴퓨터에 지시를 내리는 조종석 대화창
Codex CLI

터미널(PowerShell) 안에서 실행하는 OpenAI의 AI 코딩 에이전트입니다. 자연어로 지시하면 현재 폴더의 파일을 읽고 코드와 문서를 직접 생성·수정합니다.

💡 비유: 내 작업 폴더 안에 들어와 직접 파일을 만들어주는 터미널 상주 AI 개발자
브라우저 (Browser)

Chrome, Edge 등 웹 페이지를 화면에 그려주는 프로그램입니다. AI가 만든 quiz.html 같은 결과물을 열어 동작을 확인하는 창구입니다.

💡 역할: 코드로 작성된 결과물을 사람이 클릭하고 볼 수 있게 보여주는 화면 뷰어

1차시 핵심 개념과 용어

터미널 (Terminal)

마우스 클릭 대신 키보드로 글자 명령을 입력해 컴퓨터를 조작하는 검은색/파란색 텍스트 화면 창입니다.

CLI (Command Line Interface)

아이콘을 클릭하는 GUI와 반대되는 개념으로, 글자(명령줄)를 입력해 프로그램과 대화하는 작업 방식을 뜻합니다.

프롬프트 (Prompt)

AI에게 원하는 작업의 [역할·맥락·명령·형식·제한]을 담아 전달하는 지시문입니다. 구체적일수록 정확한 결과물이 나옵니다.

파일 (File)

데이터(.csv), 문서(.md), 프로그램 코드(.py, .html)가 컴퓨터 저장장치에 기록되는 기본 단위입니다.

권한 (Permissions & Execution Policy)

컴퓨터 보안과 안전을 위해 특정 스크립트 실행이나 파일 수정·삭제를 허용할지 통제하는 규칙입니다. PowerShell의 실행 정책(RemoteSigned)과 Codex의 도구 승인(/permissions)이 여기에 해당합니다.

2차시 신규 사용 도구

중복 제외 (Codex CLI는 1차시 참고)

데이터를 코드로 계산하고, 작업 이력을 체계적으로 저장·공유하는 핵심 개발 도구 4가지입니다.

VS Code (Visual Studio Code)

파일 탐색기, 코드 편집기, 터미널, Git 버전 관리 기능이 하나로 통합된 개발자 전용 만능 작업대입니다. 대표적인 IDE(Integrated Development Environment, 통합 개발 환경) 중 하나입니다.

💡 비유: 필기구·서류철·계산기가 한 책상에 빌트인된 스마트 워크스테이션
Python (파이썬)

사람이 읽기 쉬운 문법을 가진 프로그래밍 언어로, 대용량 표 데이터 분석(pandas), 자동화 스크립트, 웹 대시보드 제작에 표준으로 쓰입니다.

💡 역할: 2~5차시 전체에서 실제 데이터 계산과 보고서 생성을 수행하는 핵심 계산 엔진
Git (깃)

내 PC(로컬)에서 코드나 파일이 언제, 어떻게 바뀌었는지 버전별로 이력을 기록하고 과거 시점으로 되돌릴 수 있는 버전 관리 도구입니다.

💡 비유: 작업 단계마다 스냅샷을 찍어두는 로컬 타임머신
GitHub (깃허브)

Git으로 기록한 내 컴퓨터의 작업 내역을 인터넷 클라우드에 백업하고 팀원들과 공유·협업하는 원격 저장소 서비스입니다.

💡 역할: 3차시 웹앱 배포(Community Cloud)와 5차시 예약 자동화의 중심 허브

2차시 핵심 개념과 용어

CSV (Comma-Separated Values)

표 형태의 데이터를 쉼표(,)로 구분해 저장한 가벼운 텍스트 파일입니다. 엑셀에서도 열 수 있고 파이썬이 가장 빠르고 정확하게 읽는 표준 형식입니다.

집계 (Aggregation)

수백~수만 행의 개별 거래·검사 기록을 조건별로 묶어 건수, 합계, 지연 금액, 불합격률 등 요약 지표로 산출하는 과정입니다.

기준일 (As-of Date)

납기 지연이나 누적 실적을 판단하는 기준 시점 날짜(예: 2026-11-13)입니다. 기준일이 달라지면 지연 건수와 누적 합계도 달라집니다.

Git (로컬 저장소)

내 PC 폴더 안에 숨겨진 .git 공간에서 수정 전후 차이(diff)를 추적하고 버전 이력을 관리하는 시스템입니다.

commit (커밋)

작업한 파일 중 기록할 대상(git add)을 골라 설명 메시지와 함께 하나의 확정된 버전(세이브 포인트)으로 저장하는 동작입니다.

push (푸시)

내 PC에 저장된 commit 기록들을 원격 저장소(GitHub)로 업로드해 동기화하는 명령입니다.

3차시 신규 사용 도구

중복 제외 (Python, GitHub는 2차시 참고)

파이썬 분석 코드를 누구나 클릭해 볼 수 있는 웹 대시보드로 만들고 인터넷에 공개하는 도구 2가지입니다.

Streamlit (스트림릿)

HTML이나 JavaScript를 따로 배우지 않고도 순수 Python 코드만으로 필터, 차트, KPI(핵심성과지표) 카드, 다운로드 버튼이 달린 인터랙티브 웹앱을 만들어 주는 프레임워크입니다.

💡 용도: 3차시 '자재 납기 관제실'과 4차시 '용접 품질 대시보드' 화면 제작
Streamlit Community Cloud

GitHub 저장소에 올린 Streamlit 코드를 연결하면 별도 서버 구축 없이 무료로 웹 URL을 발급해 실행해 주는 클라우드 호스팅 서비스입니다.

💡 장점: 내 PC를 꺼도 동료들이 웹 링크만으로 대시보드에 접속할 수 있습니다.

3차시 핵심 개념과 용어

웹앱 (Web App)

설치 없이 웹 브라우저에서 실행되며, 사용자가 드롭다운·체크박스를 누를 때마다 실시간으로 계산해 화면을 바꿔주는 동적 프로그램입니다.

로컬 서버 (Local Server)

외부 인터넷에 공개하기 전, 내 컴퓨터 내부(localhost)에서 테스트용으로 띄우는 미니 웹 서버입니다.

포트 (Port)

한 컴퓨터 안에서 여러 프로그램이 통신할 때 겹치지 않도록 나누어 쓰는 출입구 번호입니다. Streamlit은 기본적으로 8501번 포트를 사용합니다.

의존성 (Dependencies)

내 코드가 정상 작동하기 위해 미리 설치되어 있어야 하는 외부 패키지 목록(pandas, streamlit)입니다. 보통 requirements.txt 파일에 버전과 함께 적어둡니다.

배포 (Deploy)

내 PC에서만 돌아가던 개발 결과물을 클라우드 서버에 올려 다른 사람들도 인터넷 주소(URL)로 접속해 사용할 수 있게 공개하는 최종 단계입니다.

4차시 신규 사용 도구

중복 제외 (Python, Streamlit은 2·3차시 참고)

터미널 명령어 대신 그래픽 창(GUI)에서 프로젝트 폴더를 선택해 AI 에이전트와 협업하는 도구입니다.

ChatGPT Windows 앱의 Codex

Windows용 ChatGPT 데스크톱 앱에 통합된 로컬 코딩 에이전트 기능입니다. 앱에서 내 PC의 특정 실습 폴더(starter 등)를 프로젝트로 연결하면, 채팅창을 통해 파일 분석, 코드 작성, 실행 검증을 직관적인 UI로 수행할 수 있습니다.

💡 Codex CLI와의 차이: 터미널에서 텍스트로 실행하는 것이 Codex CLI라면, 데스크톱 앱 화면에서 폴더 선택과 스킬 메뉴를 클릭하며 쓰는 것이 ChatGPT 앱의 Codex입니다.

4차시 핵심 개념과 용어

로컬 폴더 (Local Folder)

클라우드가 아닌 내 컴퓨터 하드디스크에 실제로 존재하는 작업 디렉터리입니다. 에이전트가 접근할 수 있는 작업 범위를 해당 폴더로 제한해 안전하게 실습합니다.

에이전트 (Agent)

단순히 질문에 답만 하는 챗봇을 넘어, 목표를 달성하기 위해 스스로 계획을 세우고 파일을 읽으며 코드를 실행·검증하는 자율 작업 주체입니다.

가중 비율 (Weighted Rate)

용접 불합격률을 구할 때 각 행의 비율을 단순 평균 내지 않고, 전체 불합격 수 합계 ÷ 전체 검사 수 합계 × 100으로 계산하여 검사 물량 규모가 반영된 정확한 비율입니다.

검증 (Verification)

AI가 만든 대시보드 화면 수치(예: KS-101 호선 필터 결과)가 원본 CSV에서 직접 재계산한 값과 100% 일치하는지 교차 대조해 신뢰성을 확보하는 과정입니다.

5차시 신규 사용 도구 (문서 포맷)

중복 제외 (Codex 앱, Python은 2·4차시 참고)

자동 분석 결과를 사람이 읽기 좋은 문서와 웹 보고서 형태로 출력하기 위한 표준 문서 포맷 2가지입니다.

Markdown (마크다운, .md)

#(제목), -(목록), **(강조) 같은 간단한 기호로 서식을 표현하는 경량 텍스트 문서 형식입니다.

💡 활용: AGENTS.md, SKILL.md, 일일 운영 브리핑 요약 보고서(brief_YYYY-MM-DD.md) 작성
HTML (.html)

웹 브라우저가 화면을 그릴 때 사용하는 표준 웹 문서 언어입니다. 제목(<h1>), 표(<table>), 스타일을 구조화해 깔끔한 보고서 화면을 만듭니다.

💡 활용: 1차시 퀴즈 웹페이지와 5차시 일일 운영 브리핑 HTML 보고서 생성

5차시 핵심 개념과 용어

자동화 (Automation)

사람이 매일 수작업으로 엑셀을 열고 복붙하던 반복 업무(데이터 집계, 보고서 생성, 요청 초안 작성)를 스크립트와 에이전트 스킬로 표준화해 한 번에 실행하는 것입니다.

dry-run (모의 실행 / 초안 생성)

실제 이메일 발송, 외부 전송, 운영 DB 반영 같은 되돌릴 수 없는 작업을 즉시 실행하지 않고, 결과물 초안(supplier_drafts.md)만 먼저 만들어 사람이 검토하게 하는 안전 절차입니다.

재실행 (Idempotent Re-run / 멱등성)

같은 기준일로 프로그램을 두 번 이상 다시 실행해도 결과 파일이 중복으로 쌓이지 않고 동일한 집계 수치가 일관되게 유지되는 안정적 실행 성질입니다.

원본 보존 (Source Preservation)

분석이나 보고서 생성 과정에서 기초 데이터인 원본 CSV 파일을 절대 덮어쓰거나 삭제하지 않고 읽기 전용으로 유지하는 데이터 분석의 대원칙입니다.
